# Folderly API

Express + MongoDB + S3 backend for Folderly. **Full documentation (configuration, security, deployment, API reference): see the [root README](../README.md).**

```bash
cp .env.example .env     # configure
npm install
npm run seed:admin       # first admin
npm run dev              # http://localhost:5000   (npm start for production)
```
Docs: `docs/folderly-api.postman_collection.json`, `docs/CURL_EXAMPLES.md`.
